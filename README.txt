LiteTV - lightweight ad-free launcher

GET THE APK
1. Create a new GitHub repo (e.g. "litetv") and upload everything in this folder (keep the .github folder).
2. Go to the Actions tab -> "Build LiteTV APK" runs automatically (~3 min).
3. Open the finished run -> download "LiteTV-apk" -> unzip -> rename to LiteTV.apk.

INSTALL
Option A: run tv-tweaks.bat (installs the APK + applies speed tweaks via ADB).
Option B: copy LiteTV.apk to a USB stick, open it with a file manager on the box.
Then press HOME and choose LiteTV -> Always.

YOUR APPS: nothing is uninstalled or disabled. LiteTV just lists every installed app
(TV and phone-style). The stock launcher stays installed - to go back, Settings > Apps >
LiteTV > Clear defaults, then press HOME and pick the original.

REMOTE: OK = open, hold OK = pin to top / app info. Settings button top right.
